## Getting Started

First, run the development server:

Install dependencies with node_modules:

```bash
npm i
# or
npm install
```

Next run your app:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

How to check your code design/errors:

```bash
npm run lint
npm run typecheck
npx depcheck
```
